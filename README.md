# FUTURE.exe

> Uma experiência interativa criada através de código.

## 💡 Sobre o projeto

FUTURE.exe é uma experiência web interativa desenvolvida com HTML, CSS e JavaScript.

A proposta é transformar uma simples página web em uma pequena narrativa digital, utilizando elementos de interfaces de sistemas, terminal, banco de dados, animações e interações.

Ao longo da experiência, o usuário passa por diferentes etapas até descobrir o verdadeiro propósito do sistema.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Animações CSS
- DOM Manipulation

## 🎯 Conceito

O projeto mistura programação e narrativa.

Cada etapa representa uma parte de um sistema:
